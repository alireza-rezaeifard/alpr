# Vazirmatn Font Files

This directory must contain the following font files before building the app:

- `Vazirmatn-Regular.ttf`
- `Vazirmatn-Bold.ttf`

## Download Instructions

Download the fonts from the Vazirmatn GitHub releases:

**GitHub Releases:** https://github.com/rastikerdar/vazirmatn/releases

1. Go to the latest release page.
2. Download the release archive (e.g., `vazirmatn-v33.003.zip` or similar).
3. Extract the archive and locate the TTF files inside the `fonts/ttf/` directory.
4. Copy the following files into this directory:
   - `Vazirmatn-Regular.ttf`
   - `Vazirmatn-Bold.ttf`

## Why These Fonts?

Vazirmatn is a modern Persian/Arabic typeface that provides proper RTL text rendering
required for displaying Persian license plates (Requirement 15.7).
