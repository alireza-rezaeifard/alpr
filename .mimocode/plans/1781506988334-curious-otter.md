### 2. Create `alpr_engine.py` (NEW FILE — core inference wrapper)

Single module that wraps all reference project inference logic.

**Contents:**
- Constants: `CHAR_CLASSNAMES` (28 entries), `CAR_CLASSES` (27 brands), `COLOR_CLASS_NAMES` (12 colors), thresholds
- `AlprResult` dataclass: `plate_text, plate_bbox, car_bbox, car_color, car_type, city, confidence, char_bboxes`
- `AlprEngine` class:
  - `__init__(model_dir)` — loads all 5 models + CSV with try/except per model (graceful failure)
  - `_load_yolo(name)` — loads YOLO model, returns None on failure
  - `_load_resnet(name, num_classes)` — loads ResNet18 with replaced FC layer
  - `_predict_car(vehicle_crop) -> str | None` — ResNet18 inference, returns name if prob >= 0.65
  - `_predict_color(vehicle_crop) -> str | None` — ResNet18 inference, returns color if prob >= 0.7
  - `_find_city(letter, number) -> str | None` — CSV lookup
  - `_assemble_chars(plate_crop) -> (text, confidence, char_bboxes)` — YOLO char detection sorted by x1
  - `run(frame: np.ndarray) -> list[AlprResult]` — full pipeline:
    1. car_det_model → filter classes [2,3,5,7] → crop vehicles
    2. For each vehicle: car_name (if class_id==2), color (all)
    3. plate_det_model → crop plates
    4. char_model on each plate → sort by x1 → assemble text
    5. city lookup from plate text (letter at index 2, number at indices 6-7)
